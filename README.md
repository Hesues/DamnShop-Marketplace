## Tech Stack

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui, TanStack Query
- **Backend:** Node.js, Express 5, Passport.js (session auth)
- **Database:** PostgreSQL with Drizzle ORM
- **Payments:** NOWPayments (crypto) with wallet balance system
- **Notifications:** Web Push (VAPID)

## Quick Start

1. Copy `.env.example` to `.env` and fill in your values:
   ```
   DATABASE_URL=
   SESSION_SECRET=
   NOWPAYMENTS_API_KEY=
   NOWPAYMENTS_IPN_SECRET=
   VAPID_PUBLIC_KEY=
   VAPID_PRIVATE_KEY=
   PORT=5000
   ```
2. Install and set up the database:
   ```
   npm install
   npm run db:push
   ```
3. Run in development:
   ```
   npm run dev
   ```
4. Or build and run in production:
   ```
   npm run build
   npm start
   ```

The first registered user automatically becomes the admin.
